
🪐 우주 교육 앱 기획서 (CosmoEdu)

1. 앱 개요
- 앱 이름(가칭): CosmoEdu
- 목적: 사용자가 흥미롭게 우주를 배우고, 태양계 행성·우주 현상·우주 탐사 등의 지식을 체계적으로 습득할 수 있도록 돕는 교육용 앱.
- 대상 사용자:
  - 청소년 및 성인 초보자
  - 과학에 관심은 있지만 딱딱한 교재보다 “스토리 중심”으로 배우고 싶은 사람
  - 천문학 입문자

2. 주요 콘텐츠 구성

A. 태양계 (Solar System)
- 소개 항목: 태양, 수성, 금성, 지구, 화성, 목성, 토성, 천왕성, 해왕성
- 콘텐츠 예시:
  - 각 행성의 특징, 대기 구성, 위성, 탐사 이력
  - “재미있는 에피소드” (예: 화성의 ‘운하’ 논쟁, 토성의 고리 형성 비밀 등)
  - 3D/로우폴리 이미지 및 회전 가능한 모델

B. 우주 현상 (Cosmic Phenomena)
- 주요 주제 예시:
  - 일식과 월식, 오로라, 초신성, 블랙홀과 중력 렌즈, 유성우, 성운과 별의 탄생, 혜성의 궤도 변화
- 스토리 예시:
  - 고대인들이 일식을 두려워했던 이유
  - 1919년 아인슈타인의 상대성이론을 증명한 일식 관측

C. 우주 탐사 (Space Exploration)
- 탐사선 및 프로젝트 예시:
  - 아폴로 11호 – 인류 최초의 달 착륙
  - 보이저 1호 – 태양계를 벗어난 첫 탐사선
  - 큐리오시티·퍼서비어런스 – 화성 탐사
  - 제임스 웹 망원경 – 우주 초기 관측
  - 아르테미스 프로젝트 – 차세대 달 탐사 계획
- 콘텐츠 구성:
  - 연대기 타임라인
  - 임무별 요약, 임무 목적, 주요 성과
  - 실제 탐사 영상 또는 시각화 이미지

3. 앱 기능 구성
- 홈 화면, 행성/현상 상세, 학습 카드, 타임라인, 즐겨찾기, 다크모드, 알림 기능

4. 디자인 컨셉
- 스타일: 로우폴리 + 다크톤 + 네온 포인트
- 컬러 팔레트: 짙은 남색(#0A0F2C), 보라(#6C63FF), 주황(#FFB347)
- UI 특징: 행성 궤도형 네비게이션, 카드 기반 정보 표시, 애니메이션 전환

5. 향후 확장 아이디어
- AR 모드로 “내 방에서 태양계 보기”
- 실시간 우주 뉴스 피드 연동
- NASA 오픈 API 연결
- 사용자 퀴즈 챌린지 기능

6. 개발 메모
- 개발 스택: Flutter
- 데이터 저장: Firebase 또는 SQLite
- 이미지 스타일: 로우폴리 + NASA 공공 데이터
